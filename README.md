# Formula Selector

A small React + Vite app for baby formula catalog, barcode validation, nutrition calculator, and clinical rule evaluation.

## Features

- EAN-8 / EAN-13 validation with checksum
- Barcode camera scanner via `@zxing/library`
- Daily calorie and nutrient calculation
- Clinical recommendation rules for formula selection
- Product catalog with filtering and search
- Responsive UI

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
```
