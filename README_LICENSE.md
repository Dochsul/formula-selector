# Formula Selector — License System

## Система лицензирования (без ИП)

Это легальная система управления подписками без требования регистрации в качестве ИП или самозанятого.

### Как это работает

1. **Пользователь регистрируется** с email и паролем
2. **Выбирает тариф**:
   - 499 ₽ / месяц
   - 1499 ₽ / квартал
   - 3999 ₽ / год
3. **Получает инструкцию оплаты** на ваш личный счёт
4. **Платит** на указанные реквизиты
5. **Подтверждает оплату** в системе (или вы подтверждаете вручную)
6. **Получает персональный ключ лицензии**
   - Привязан к email
   - Действует определённый срок
   - Один email = одна активная лицензия
7. **Использует ключ для доступа** к приложению

### API Endpoints

#### Аутентификация

```bash
# Регистрация
POST /api/register
{
  "email": "user@example.com",
  "password": "secure_password"
}

# Вход
POST /api/login
{
  "email": "user@example.com",
  "password": "secure_password"
}
```

#### Лицензии

```bash
# Получить инструкцию оплаты
POST /api/license/request
{
  "email": "user@example.com",
  "plan": "monthly" | "quarterly" | "yearly"
}

# Проверить лицензию
GET /api/license/check?email=user@example.com&key=FS-XXXXX

# Получить лицензии пользователя
GET /api/licenses/me?email=user@example.com
```

#### Оплата

```bash
# Подтвердить оплату и создать лицензию
POST /api/payment/manual-confirm
{
  "email": "user@example.com",
  "plan": "monthly" | "quarterly" | "yearly"
}
```

### Тарифы

| План | Цена | Срок |
|------|------|------|
| Месяц (monthly) | 499 ₽ | 30 дней |
| Квартал (quarterly) | 1499 ₽ | 90 дней |
| Год (yearly) | 3999 ₽ | 365 дней |

### Безопасность

- ✅ Лицензии привязаны к email
- ✅ Один email = одна активная лицензия
- ✅ Срок действия проверяется при каждом запросе
- ✅ Пароли хранятся в хешированном виде
- ✅ API ключи генерируются как UUID
- ✅ Доступ ограничен по лицензии

### Примечание

Эта система полностью легальна и не требует:
- ИП или ООО
- Самозанятости
- Регистрации в платёжной системе

Получение платежей происходит напрямую на личный счёт/карту с подтверждением оплаты.
